=========================================================
JAVA PRACTICALS - QUICK RUN STEPS (SHORT + WORKING)
=========================================================

1) DATABASE (run once in psql)
---------------------------------------------------------
CREATE DATABASE practicaldb;
\c practicaldb

CREATE TABLE IF NOT EXISTS student (
  id SERIAL PRIMARY KEY,
  roll_no INT,
  name VARCHAR(100),
  branch VARCHAR(50)
);

CREATE TABLE IF NOT EXISTS feedback (
  id SERIAL PRIMARY KEY,
  visitor_name VARCHAR(100),
  email VARCHAR(100),
  message TEXT,
  rating INT,
  submitted_at TIMESTAMP
);

2) JARS NEEDED
---------------------------------------------------------
- PostgreSQL JDBC jar: C:\jars\postgresql.jar
- Tomcat 9 already installed (apache-tomcat-9.0.111)
- For Hibernate (exp8, exp9): keep all hibernate jars in C:\jars\hib\*
- For Struts2 (exp6, exp7): keep Struts 2.5.x jars in C:\jars\struts\*

3) EXP 1 (JDBC CONNECTION)
---------------------------------------------------------
cd exp1_jdbc
javac -cp .;C:\jars\postgresql.jar JdbcConnection.java
java  -cp .;C:\jars\postgresql.jar JdbcConnection

4) EXP 2, 3 (JSP)
---------------------------------------------------------
Copy exp2_jsp_basic\index.jsp to:
apache-tomcat-9.0.111\webapps\exp2\

Copy exp3_jsp_insert\form.jsp and insert.jsp to:
apache-tomcat-9.0.111\webapps\exp3\

Put postgresql.jar in:
apache-tomcat-9.0.111\lib\

Start Tomcat:
apache-tomcat-9.0.111\bin\startup.bat

Open:
http://localhost:8080/exp2/index.jsp
http://localhost:8080/exp3/form.jsp

5) EXP 4 (SERVLET VALIDATION)
---------------------------------------------------------
mkdir apache-tomcat-9.0.111\webapps\exp4\WEB-INF\classes
copy exp4_servlet_validation\index.html apache-tomcat-9.0.111\webapps\exp4\

javac -cp .;apache-tomcat-9.0.111\lib\servlet-api.jar -d apache-tomcat-9.0.111\webapps\exp4\WEB-INF\classes exp4_servlet_validation\UserValidationServlet.java

Open:
http://localhost:8080/exp4/index.html

6) EXP 5 (CALL ONE SERVLET BY ANOTHER)
---------------------------------------------------------
mkdir apache-tomcat-9.0.111\webapps\exp5\WEB-INF\classes
copy exp5_servlet_call\index.html apache-tomcat-9.0.111\webapps\exp5\

javac -cp .;apache-tomcat-9.0.111\lib\servlet-api.jar -d apache-tomcat-9.0.111\webapps\exp5\WEB-INF\classes exp5_servlet_call\FirstServlet.java exp5_servlet_call\SecondServlet.java

Open:
http://localhost:8080/exp5/index.html

7) EXP 6 (STRUTS LOGIN)
---------------------------------------------------------
